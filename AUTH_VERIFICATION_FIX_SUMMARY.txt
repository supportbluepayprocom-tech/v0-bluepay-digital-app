================================================================================
                           AUTH FLOW - SIGNUP
================================================================================

FLOW:
1. User enters Full Name & Email
2. System checks email doesn't exist (via /api/auth/check-email)
3. Account created if email is new
4. OTP sent to email
5. ONLY START COOLDOWN after successful OTP delivery
6. User enters OTP on verify-email page
7. OTP verified via /api/auth/verify-otp
8. Profile and wallet created/updated
9. Redirect to /dashboard

================================================================================
                           AUTH FLOW - SIGNIN
================================================================================

FLOW:
1. User enters email
2. System verifies account EXISTS (via /api/auth/verify-account)
3. If not found: show "Please create account" + redirect to signup
4. If found: send OTP to email
5. ONLY START COOLDOWN after successful OTP delivery
6. User enters OTP on verify-email page
7. OTP verified
8. Redirect to /dashboard
